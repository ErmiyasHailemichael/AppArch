Architectural style

A Ruby on Rails monolith, deployed as three processes. The web app, the Sidekiq background workers and the API share one codebase. A separate Node.js server handles streaming. PostgreSQL stores the data and Redis holds feeds and job queues.

Two more styles show up on top of that: asynchronous job queues (work after the response goes to Sidekiq) and a federated network (servers exchange posts over ActivityPub). It is not a microservices system.
